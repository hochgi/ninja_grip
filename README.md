# Ninja Grip 🥷

Jogo web de nínjas em HTML/JS/Canvas, feito para telemóvel (RTL, hebraico).

## Jogos incluídos
- **Nínja Grip** (`ninja-grip.html`) — jogo principal: balançar entre barras, evitar cair, apanhar moedas, comprar skins, lutar contra bosses, e um mini-jogo de escondidas embutido.

## Como correr
Abrir `ninja-grip.html` diretamente no browser (sem dependências, sem build step).
